# Roadmap

## Gate 0 — upstream fit

Deliverables:

- APOA compatibility matrix;
- proposed document profile;
- maintainer contact or upstream issue;
- licensing and attribution review.

Proceed if the profile can remain compatible without a core fork.

## Gate 1 — verifier-first prototype

Deliverables:

- normative fixture;
- profile verifier;
- negative tests for changed hash, missing approval, expiry, and duplicate execution;
- architecture and threat model.

Proceed when fixtures are deterministic and no production credentials are required.

## Gate 2 — one end-to-end NDA flow

Deliverables:

- frozen PDF hash;
- passkey-capable approval ceremony;
- APOA mandate;
- one mocked or sandbox provider adapter;
- signed or integrity-protected execution receipt;
- 60–90 second demo.

Proceed when an independent verifier can explain exactly what was authorized and executed.

## Gate 3 — pilots

Target three design partners: one legal practice, one document-heavy business, and one UAE innovation partner.

Measure completion time, manual steps removed, approval abandonment, verifier acceptance, failures prevented, and integration effort.

## Gate 4 — ecosystem decision

Only after pilot evidence decide whether to:

- maintain a document profile around APOA;
- contribute generic extensions upstream;
- form a neutral interoperability group;
- pursue a UAE regulatory sandbox;
- build commercial hosted services around the open profile.

Stop or pivot if counterparties will not consume the evidence, provider integration is contractually blocked, or the legal ceremony cannot be separated from human-only execution.
